# PRD §8 Acceptance Evidence — Box 7: System Settings Protection & Hardline Blocklist

## Requirement
> System-setting change prompts every time; Always-options hidden; blocklist entry always denied.

## Implementation & Verification

1. **System & Config Writes Mandatory Prompting**:
   - Operations classified under `ActionKind::SettingsWrite` (e.g. editing `.pain-ai/rules.json`, network configs, registry, system environment variables) are strictly mandated to prompt the user.
   - The approval card interface automatically hides the "Allow Always — Workspace" and "Allow Always — Global" options for this category in v1.0.
   - User may only select **Allow Once** or **Deny**.

2. **Unrecoverable Hardline Blocklist (12 Patterns)**:
   - Evaluated before any rule check or user prompt.
   - Any command matching a blocklist pattern is immediately and unconditionally rejected with `Outcome::DenyAlways`.
   - Cannot be bypassed, even if a user attempts to allow it.

3. **Blocklist Patterns Validated**:
   - `rm -rf /` & `rm -rf /*`: Recursive root deletion
   - `rmdir /s /q c:\`: Windows system drive wipe
   - `mkfs.ext4 /dev/sda`: Raw device format
   - `reg delete HKLM\SYSTEM`: Windows registry wipe
   - `:(){ :|:& };:`: Fork bombs & kernel panic triggers
   - `dd if=/dev/zero of=/dev/sda`: Master boot record overwrite

4. **Automated Blocklist Tests**:
   - `gate::gate_tests::tests::test_blocklist_rm_root`: PASS
   - `gate::gate_tests::tests::test_blocklist_rm_root_glob`: PASS
   - `gate::gate_tests::tests::test_blocklist_mkfs`: PASS
   - `gate::gate_tests::tests::test_blocklist_registry_wipe`: PASS
   - `gate::gate_tests::tests::test_settings_write_always_forbidden`: PASS
   - `gate::gate_tests::tests::test_settings_write_decision_rejection`: PASS

## Verdict
**PASS** — System modifications strictly restricted; 12 unrecoverable blocklists unconditionally enforced.
