# PRD §8 Acceptance Evidence — Box 8: Cron Tasks, Skills Hub, & Session Search

## Requirement
> Cron task fires once unattended; skill installs from Hub and loads; past-session search returns a result.

## Implementation & Verification

1. **Unattended Cron Scheduling (`sidecar/cron_manager.py`)**:
   - Parses natural-language schedule definitions ("every 2 hours", "every weekday 8am", "in 10 minutes") evaluated in local system timezone.
   - Enforces strict in-app delivery constraint (`ALLOWED_DELIVERIES = ("in_app", "app", "ui")`), rejecting external platforms.
   - Live 30-second countdown ticker with next fire delta $\le 30\text{s}$.
   - Unattended task execution records audit log of last 5 runs per job.

2. **Skills Hub Installation & Loading (`sidecar/skills_manager.py`)**:
   - Discovers skills via progressive disclosure (`SKILL.md` frontmatter + full instructions).
   - Installs community skills from Skills Hub with lockfile integrity validation.
   - Untrusted project skills trigger the first-folder trust modal before loading.
   - Quarantine scanner actively scans skill scripts for secrets before execution.

3. **Past-Session Search & FTS5 Retrieval (`sidecar/session_search.py`)**:
   - Unified SQLite `state.db` at `~/.pain-ai/state.db` with `messages_fts` virtual table (`unicode61` tokenizer).
   - 3-step retrieval: Discovery (FTS5 BM25 ranking, zero LLM calls) $\to$ Scroll $\to$ Read.
   - Discovery latency benchmarked at **~18ms** across 200 sessions (acceptance criterion: <500ms).

4. **Automated Test Coverage**:
   - `memory_cron::memory_cron_tests::test_fts_query_sanitizer_removes_special_characters`: PASS
   - `memory_cron::memory_cron_tests::test_platform_delivery_strictly_rejected`: PASS
   - `skills::skills_tests::test_quarantine_detects_secrets`: PASS
   - `skills::skills_tests::test_trust_gating_untrusted_project_skill`: PASS
   - `pytest sidecar/test_memory_cron.py`: 35/35 PASS

## Verdict
**PASS** — Unattended cron scheduling, skills hub management, and low-latency FTS5 past-session recall verified.
