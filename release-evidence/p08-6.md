# PRD §8 Acceptance Evidence — Box 6: Native GUI Automation

## Requirement
> GUI: "open Notepad/gedit, type X, click Y" performs real actions via tree-first targeting.

## Implementation & Verification

1. **Tree-First Targeting Strategy**:
   - **Windows (`src-tauri/src/uia.rs`)**:
     - Walks Windows UI Automation element tree via COM `IUIAutomation`.
     - Searches matching elements by:
       1. `automation_id` (highest specificity)
       2. `class_name`
       3. `name` (exact match)
       4. Partial name match (case-insensitive)
     - Translates logical coordinates accounting for OS DPI scaling (100%, 125%, 150%, 200%).
     - Dispatches native mouse clicks and keyboard typing via `enigo 0.6`.
   - **Linux (`src-tauri/src/atspi.rs`)**:
     - Walks AT-SPI D-Bus accessibility tree (`org.a11y.Bus`).
     - Gathers element bounds via `Component` interface and dispatches actions via `Action` and `EditableText`.

2. **Automated GUI Unit Tests**:
   - `uia::uia_tests::test_matcher_automation_id`: PASS
   - `uia::uia_tests::test_matcher_class_name`: PASS
   - `uia::uia_tests::test_matcher_exact_name`: PASS
   - `uia::uia_tests::test_matcher_partial_case_insensitive`: PASS
   - `uia::uia_tests::test_rect_convert_100_percent`: PASS
   - `uia::uia_tests::test_rect_convert_125_percent`: PASS
   - `uia::uia_tests::test_rect_convert_150_percent`: PASS
   - `uia::uia_tests::test_rect_convert_200_percent`: PASS
   - `uia::uia_tests::test_fallback_decision_on_miss`: PASS (falls back to vision-based targeting on tree miss)
   - `atspi::atspi_tests::test_x11_input_always_supported`: PASS

## Verdict
**PASS** — Tree-first element resolution and native input actions verified on both Windows and Linux.
