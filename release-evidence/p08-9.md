# PRD §8 Acceptance Evidence — Box 9: Prohibition of Auto-Approve & YOLO Modes

## Requirement
> No `smart/off/YOLO` string enables auto-approve (assert in code + config).

1. **Config & Policy Hardening (`Nothing-do.md` §2 & `PRD.md` §5)**:
   - `approvals.mode` is locked strictly to `manual` (delegated to Rust `gate::check`).
   - `smart`, `off`, and `YOLO` modes are strictly forbidden.
   - Any attempt to configure `--yolo`, `HERMES_YOLO_MODE=1`, or bypass flags triggers an explicit startup panic or configuration error.

2. **Codebase Assertions**:
   - `src-tauri/src/sidecar.rs`:
     - Hardcoded environment injection:
       ```rust
       cmd.env("HERMES_APPROVALS_MODE", "manual");
       cmd.env("HERMES_TERMINAL_BACKEND", "local");
       ```
     - No mechanism exists to alter this environment variable at runtime.
   - `src-tauri/src/gate.rs`:
     - Gate evaluation unconditionally prompts unless an explicit user-approved rule exists in `rule_store`.
     - No "auto-approve classifier" or bypass heuristic exists.

3. **Forbidden Mode Static Grep Audit**:
