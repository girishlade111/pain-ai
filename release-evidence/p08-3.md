# PRD §8 Acceptance Evidence — Box 3: Synchronous Voice & Captions

## Requirement
> Voice prompt → voice audio + on-screen caption simultaneously (caption visible while audio plays).

## Implementation & Verification

1. **Single Event, Dual Render Architecture**:
   - When the agent completes a message turn, the sidecar emits a single `message_completed` SSE event with `{ id, text }`.
   - The frontend handler dispatches two simultaneous actions:
     - `voiceSpeak(sentences)` via Tauri IPC to the native audio engine (`src-tauri/src/audio.rs`).
     - Zustand `setCaptionState({ sentences, activeI: 0, state: 'playing' })`.
   - The LLM is never invoked twice for voice vs text.

2. **Synchronous Caption Highlighting**:
   - `audio.rs` emits `voice_state { active_i, state: "playing" | "done" }` as each sentence audio finishes.
   - `<CaptionBar />` renders at the bottom of the viewport with active sentence highlighting and animated waveform indicator.
   - Caption remains visible throughout the entire playback duration and auto-settles to `done` on completion.

3. **Chibi Companion Synchronization (P11c)**:
   - Voice `playing` state automatically transitions the chibi mascot overlay to `talk` animation.
   - On audio completion, chibi returns to `idle`.
